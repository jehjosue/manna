## Avisos de Revisão Humana

1. **Verificar adaptações narrativas**: As histórias foram expandidas com diálogos e cenários que, embora fiéis ao texto, representam interpretações criativas. Revisor humano deve validar se permanecem teologicamente corretas.

2. **Validar traduções de Almeida Antiga**: Algumas citações foram adaptadas ligeiramente para concordância com outras versões de domínio público. Revisor deve comparar com originais.

3. **Confirmar exercícios e contexto**: Os exercícios (multipleChoice, trueFalse, etc.) foram criados para teste educativo. Revisor deve validar se as opções erradas não são pedagogicamente enganosas.

4. **Checar consistência teológica**: As 24 lições de Salmos e Atos apresentam ensinamentos consensuais entre tradições (evangélica e católica), mas revisor deve garantir que nenhuma ênfase é denominacional.

5. **Validar histórias para idade**: Histórias foram adaptadas para públicos cristãos gerais (iniciantes a avançados). Revisor deve garantir que tom e conteúdo são apropriados para todas as faixas etárias.
